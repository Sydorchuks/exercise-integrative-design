Design notes

✅ Every autism-friendly rule we follow — and how to see it

✅

No flashing, blinking, or rapidly changing visuals

The background and all elements are completely static. No CSS animations change color at speed. No GIFs, no autoplay video. This prevents seizures and sensory overload.

How to see it: Every element on this page is still. Compare to the breaking-rules page where the entire background flashes every 0.4 seconds.

✅

Respects prefers-reduced-motion

The CSS @media (prefers-reduced-motion: reduce) rule disables ALL transitions and animations if the user has set this in their operating system. This is the most important accessibility setting for motion-sensitive individuals.

How to see it: Enable "Reduce Motion" in your OS accessibility settings, then inspect the CSS — all transitions become instant.

✅

Calm, consistent, muted color palette

The palette uses soft sage green (--primary: #3d6b52) and warm off-white (--bg: #f7f5f0). No red/green clashes, no rainbow gradients, no neon colors. Accent color (amber) is used only sparingly for labels. All text meets WCAG AA contrast ratio (4.5:1 minimum).

How to see it: The entire page uses only 2-3 hues. There are no jarring color transitions anywhere.

✅

Consistent typography — readable fonts, adequate sizing

Body text uses DM Sans at 18px (above the 16px minimum) with line-height 1.7. The display font (DM Serif Display) is used ONLY for headings, never for body text. Font sizes follow a clear, logical hierarchy: h1=2.8rem, h2=1.8rem, h3=1.1rem, body=1rem. No text smaller than 0.85rem anywhere. No Comic Sans or display fonts for reading text.

How to see it: Every paragraph is the same size and font. Headings decrease logically in size. No text is unreadably small.

✅

Text is never justified — always left-aligned

Justified text creates uneven word spacing ("rivers" of white space) that makes reading harder for dyslexic and autistic readers. Every paragraph on this page uses text-align: left.

How to see it: All paragraphs align to the left edge. There is no stretched word spacing.

✅

Predictable, consistent layout — same structure throughout

Every section uses the same grid, the same card structure, the same heading pattern. Nothing is rotated, skewed, or placed unexpectedly. The navigation is in the same place on every page.

How to see it: The page flows top-to-bottom in a clear column. All cards are the same width and structure. Nothing is tilted or displaced.

✅

No moving text (no marquees, no tickers)

Moving text is impossible to read for many users with tracking difficulties and constantly pulls attention. There is no marquee, no ticker, no scrolling text anywhere on this page.

How to see it: All text is stationary. Nothing scrolls across the screen.

✅

No automatic popups or unexpected interruptions

Nothing opens without user action. There are no modals that auto-appear, no cookie consent banners that slide in, no chat widgets that pop up, no alerts. Users are never surprised by something appearing uninvited.

How to see it: Load the page — nothing pops up. Compare to the breaking-rules page where a red popup appears after 1.5 seconds.

✅

No autoplay audio or video

Unexpected sound is one of the most distressing sensory triggers. This page plays no audio whatsoever without user action. No background music, no sound effects, no random beeps.

How to see it: Load the page with your audio on — silence. Compare to the breaking-rules page which plays random beeps every 2-4 seconds.

✅

Links are clearly identifiable and distinguishable

All links in body content and footer are underlined. Navigation links have clear hover states that change color (not transform). Links never look like plain text. No "click here" — links describe their destination.

How to see it: See the footer — all links have underlines. Hover over a nav link — only the background color changes, no rotation.

✅

Forms have visible labels, hints, and clear error feedback

Every input has a visible <label> element associated with it. Hint text explains what format is expected. Required fields are marked with both an asterisk AND the word "(required)". Error messages are specific and appear next to the relevant field.

How to see it: Look at the contact form below — every field has a label above it, hint text, and required marking. Try submitting without filling it in.

✅

Adequate touch/click targets (min 48×48px)

All buttons, links, and interactive elements have a minimum height of 48px and adequate padding. This ensures users with motor difficulties can reliably interact with them.

How to see it: Inspect any button — min-height: 48px is set. Compare to the breaking-rules page where the close button is 10px and hard to click.

✅

No distracting decorations or overlaid animations

No spinning emojis, no floating shapes, no background particles, no custom cursors. Decorative elements (the 🌿 logo icon, card icons) are static and marked aria-hidden so screen readers ignore them.

How to see it: The cursor is the default arrow. No shapes move anywhere on the page. All icons are still.

✅

Clear focus indicators for keyboard navigation

Every interactive element shows a clear 3px green outline when focused via keyboard (Tab key). The focus style is the same across all elements for consistency and predictability.

How to see it: Press Tab to navigate — a green outline will clearly show which element is focused.

✅

Skip navigation link for keyboard users

A "Skip to main content" link is the first focusable element. It becomes visible when focused via keyboard, allowing users to bypass the navigation and go directly to content.

How to see it: Press Tab immediately after loading — a green "Skip to main content" button appears at the top.

✅

Predictable, plain-English navigation labels

Navigation uses clear, plain words: "Home", "Courses", "About Us", "Resources", "Contact". No jargon, no puns, no ambiguous icons. The current page is marked with aria-current="page".

How to see it: Look at the header navigation — all labels are simple English words. "Home" is highlighted as the current page.

✅

Calm, plain language — no urgency, no alarm, no pressure

No "Act Now!", "Limited Time!", "Don't Miss Out!" language anywhere. The tone is calm, direct, and informative. Headings state facts, not emotional commands.

How to see it: Read any heading or CTA. None use urgency language. Compare to the breaking-rules marquee: "ACT NOW ACT NOW ACT NOW".

✅

Legible footer — never invisible text

Footer uses #5c5c5c (dark grey) on #ffffff (white) — a contrast ratio of 7:1. Font size is 0.9rem (16.2px). No text is hidden by matching its color to the background.

How to see it: The footer is fully readable. Compare to the breaking-rules page where footer text is 6px and black on near-black.
